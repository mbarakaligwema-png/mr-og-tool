## 🔌 JINSI YA KUUNGANISHA SIMU

### Hatua 1 — Washa USB Debugging
1. Nenda **Settings → About Phone**
2. Bonyeza **Build Number** mara **7** hadi uone "Developer Mode ON"
3. Rudi **Settings → Developer Options**
4. Washa **USB Debugging** ✅
5. Unganisha simu kwa USB
6. Simu itauliza ruhusa — chagua **"ALWAYS ALLOW"**

### Hatua 2 — Angalia Tool
- Chini ya tool utaona: **Port: ADB (Model ya Simu)** ikiwa imefanikiwa
- Rangi ya kijani = Simu imeunganishwa vizuri ✅
- Rangi ya njano = Unahitaji kutoa ruhusa kwenye simu

## 🔒 SAMSUNG KG LOCK — MAELEZO

### KG Lock ni nini?
KG Lock (Knox Guard) ni lock ya Samsung inayozuia simu isitumike hadi malipo yafanyike. Tool hii inazuia Knox Guard kufanya kazi.

### Jinsi inavyofanya kazi:
1. Unganisha simu ya Samsung kwa USB
2. Nenda **SAMSUNG** tab
3. Bonyeza **"KG MANUALLY"**
4. Tool itaweka DNS ya NextDNS inayozuia servers za Samsung
5. Simu haiwezi kuwasiliana na Samsung Knox servers
6. KG Lock haiwezi kuwashwa / ku-activate

### Servers Zinazozuiwa (Auto):
```
samsungknox.com, kgclient.samsung.com, 
fmm.samsung.com, ospserver.net, na nyingine...
```

## ❓ MASWALI YA KAWAIDA (FAQ)

**Q: Tool haifunguki — inasema "Server Connection Error"**
> A: Hakikisha una internet. Zima VPN kama unatumia. Jaribu tena.

**Q: Simu haionekani kwenye tool**
> A: Hakikisha USB Debugging imewashwa. Badilisha cable. Bonyeza ALLOW kwenye simu.

**Q: "Unauthorized" inaonekana**
> A: Angalia simu yako — itakuuliza kutoa ruhusa. Bonyeza "Allow/Ruhusa" ✅

**Q: KG Lock inarudi baada ya ku-restart simu**
> A: Hakikisha umefanya KG MANUALLY vizuri. Tool inahitaji kuwa Device Owner.

**Q: Account yangu imekwisha (Expired)**
> A: Wasiliana na admin kupitia WhatsApp au mrogtool.com ili uongeze muda.
